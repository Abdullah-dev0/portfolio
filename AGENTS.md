# Naming conventions

- Use camelCase for file names and variables, including constants (for example, `visitorStats.tsx` and `visitorId`).
- Keep React component names and TypeScript type names in PascalCase, as required by their conventions.
- Preserve framework-required file names and exports, environment variable names, and external API field names.

# Verification

- Do not automatically run lint, type-check, or build commands after a task. Ask first unless a check is important for the change.
